## Канбан-доска

GitHub Projects не наполняется сам: карточки на доске берутся из задач (Issues)
репозитория. Поэтому порядок такой.

### Шаг 1. Создать доску

Вкладка Projects -> New project -> шаблон Board -> название «Учебная практика УП.02».

Колонки по заданию практики: `Backlog`, `To Do`, `In Progress`, `Review`, `Done`.
Шаблон Board создаёт три колонки (Todo, In Progress, Done) - недостающие
добавляются кнопкой «+» справа от заголовков.

### Шаг 2. Вариант А: добавить карточки вручную (без установки программ)

На доске под нужной колонкой нажать `+ Add item`, вписать название и нажать Enter.
Так создаётся карточка-черновик: отдельная задача (issue) при этом не нужна.

Колонка `Done` - то, что уже сделано:

```
Структура проекта, README и .gitignore
Модели данных и схема базы
Регистрация и вход по JWT
API досок и задач с разграничением прав
Интерфейс доски с перетаскиванием карточек
Автотесты API и интерфейса
```

Колонка `Backlog` - развитие проекта:

```
Комментарии к задачам
История изменений задачи
Фильтр по исполнителю и приоритету
Экспорт доски в CSV
Поддержка нескольких досок
Уведомления о назначении задачи
```

Колонки `To Do`, `In Progress` и `Review` на момент сдачи первого цикла пустые -
это нормально и показывает реальное состояние работ.

### Шаг 2. Вариант Б: создать задачи скриптом

Нужен GitHub CLI:

```bash
winget install GitHub.cli
gh auth login          # вход через браузер
```

Затем из корня проекта:

```bash
bash scripts/setup-github.sh            # создаст метки и 12 задач
bash scripts/setup-github.sh 1          # перенесёт их на доску номер 1
```

Номер доски виден в её адресе: `github.com/users/gleb-khryapin/projects/<номер>`.

### Шаг 3. Распределить карточки

| Колонка | Какие задачи |
|---|---|
| Done | шесть задач первого цикла: структура, модели, вход по JWT, API, интерфейс, автотесты |
| Backlog | шесть задач на развитие: комментарии, история изменений, фильтры, экспорт, несколько досок, уведомления |

## Связь задач с ветками и коммитами

Если в сообщении коммита или в описании pull request написать `Closes #3`,
то при слиянии в `main` задача номер 3 закроется автоматически, а её карточка
на доске перейдёт в колонку `Done`. Так доска остаётся в актуальном состоянии
без ручного перетаскивания.
