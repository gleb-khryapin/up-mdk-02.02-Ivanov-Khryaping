# Описание API

Базовый адрес: `http://127.0.0.1:8000/api`
Интерактивная документация: `http://127.0.0.1:8000/docs`

Все запросы, кроме регистрации и входа, требуют заголовок:

```
Authorization: Bearer <токен>
```

## Авторизация

| Метод | Путь | Описание | Коды ответа |
|---|---|---|---|
| POST | `/auth/register` | Регистрация участника | 201, 409 почта занята, 422 ошибка данных |
| POST | `/auth/login` | Вход по почте и паролю | 200, 401 неверные данные |
| GET | `/auth/me` | Текущий пользователь | 200, 401 |
| GET | `/auth/users` | Список участников команды | 200, 401 |

## Доски и задачи

| Метод | Путь | Описание | Кто может |
|---|---|---|---|
| GET | `/boards` | Список досок | любой участник |
| POST | `/boards` | Создать доску | только тимлид |
| GET | `/boards/{id}` | Доска с колонками и задачами | любой участник |
| POST | `/boards/{id}/tasks` | Создать задачу | любой, но назначить другому - только тимлид |
| PATCH | `/boards/{id}/tasks/{task_id}` | Изменить задачу | тимлид или исполнитель |
| PATCH | `/boards/{id}/tasks/{task_id}/move` | Перенести карточку | тимлид или исполнитель |
| DELETE | `/boards/{id}/tasks/{task_id}` | Удалить задачу | только тимлид |

## Коды ошибок

| Код | Когда возникает |
|---|---|
| 401 | Токен отсутствует, повреждён или просрочен |
| 403 | Роль не позволяет выполнить действие |
| 404 | Доска или задача не найдена |
| 409 | Почта уже занята либо превышен лимит задач в колонке |
| 422 | Данные не прошли проверку: короткое название, неизвестный статус, отрицательная оценка |

## Пример: создание задачи

Запрос:

```json
POST /api/boards/1/tasks
{
  "title": "Реализовать вход по JWT",
  "description": "Форма входа и хранение токена",
  "status": "todo",
  "priority": "high",
  "assignee_id": 2,
  "branch": "feature/auth-jwt",
  "estimate_hours": 4
}
```

Ответ `201 Created`:

```json
{
  "id": 7,
  "board_id": 1,
  "title": "Реализовать вход по JWT",
  "status": "todo",
  "priority": "high",
  "position": 0,
  "author_id": 1,
  "assignee_id": 2,
  "branch": "feature/auth-jwt",
  "estimate_hours": 4.0
}
```
