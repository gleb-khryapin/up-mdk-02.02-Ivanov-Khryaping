# План тестирования

Ответственный за тестирование: тимлид.

## Что проверяется автоматически

### Серверная часть, 30 тестов (`tests/backend`)

| Файл | Проверок | Что покрывает |
|---|---|---|
| `test_auth.py` | 7 | регистрация, занятая почта, короткий пароль, вход, неверный пароль, доступ без токена, подделанный токен |
| `test_permissions.py` | 6 | ограничения роли разработчика, права тимлида, создание доски с пятью колонками |
| `test_tasks.py` | 10 | значения по умолчанию, пять вариантов некорректных данных, нумерация карточек, частичное обновление, несуществующие задача и доска |
| `test_board_rules.py` | 7 | перенос между колонками, лимит задач в работе, откат при превышении, пересчёт позиций, права на перенос |

### Интерфейс, 7 тестов (`tests/frontend`)

| Файл | Проверок | Что покрывает |
|---|---|---|
| `TaskCard.test.tsx` | 4 | отображение названия, исполнителя и ветки, перевод приоритета, скрытие кнопки удаления от разработчика |
| `BoardColumn.test.tsx` | 3 | заголовок и счётчик задач, подсказка в пустой колонке, подсветка достигнутого лимита |

## Ключевые тест-кейсы

| № | Сценарий | Ожидаемый результат |
|---|---|---|
| 1 | Разработчик создаёт доску | 403, доска не создана |
| 2 | Разработчик назначает задачу тимлиду | 403 |
| 3 | Разработчик создаёт задачу себе | 201 |
| 4 | Разработчик двигает чужую карточку | 403 |
| 5 | Разработчик двигает свою карточку | 200 |
| 6 | Четвёртая задача переносится в колонку «В работе» | 409, задача остаётся в прежней колонке |
| 7 | Название задачи короче трёх символов | 422 |
| 8 | Оценка часов отрицательная | 422 |
| 9 | Запрос без токена | 401 |
| 10 | Карточка перенесена из середины колонки | позиции оставшихся идут подряд без пропусков |

## Проверки вручную

1. Перетаскивание карточки мышью между всеми колонками.
2. Поведение при недоступном сервере: интерфейс показывает сообщение, а не пустой экран.
3. Переключатель «только мои задачи» скрывает чужие карточки.
4. После обновления страницы вход сохраняется (токен в браузере).
5. Кнопка удаления видна тимлиду и скрыта у разработчика.

## Запуск

```bash
src\backend\.venv\Scripts\python -m pytest     # серверная часть
npm test                                        # интерфейс
```
