# Бэклог проекта

Задачи для переноса на канбан-доску GitHub Projects (задача 2.4 практики).
Колонки доски: Backlog, To Do, In Progress, Review, Done.

## Первый цикл разработки (задача 3.1)

Тимлид декомпозировал задание на пять задач:

| № | Задача | Ветка | Исполнитель | Оценка |
|---|---|---|---|---|
| 1 | Структура проекта, README, .gitignore | `chore/project-structure` | тимлид | 1 ч |
| 2 | Модели данных и схема базы | `feat/db-models` | разработчик | 3 ч |
| 3 | Регистрация и вход по JWT | `feat/auth-jwt` | разработчик | 4 ч |
| 4 | API досок и задач с разграничением прав | `feat/tasks-api` | разработчик | 5 ч |
| 5 | Интерфейс доски с перетаскиванием карточек | `feat/board-ui` | разработчик | 6 ч |

## Бэклог на развитие

| Задача | Приоритет | Комментарий |
|---|---|---|
| Фильтр задач по исполнителю и приоритету | средний | частично сделано: есть переключатель «только мои задачи» |
| Комментарии к задачам | средний | обсуждение прямо в карточке |
| История изменений задачи | низкий | кто и когда менял статус |
| Экспорт доски в CSV | низкий | для отчёта по практике |
| Несколько досок на команду | низкий | сейчас работа идёт с одной доской |
| Уведомления о назначении задачи | низкий | письмо или сообщение в Telegram |

## Соглашение об именовании веток

| Префикс | Назначение | Пример |
|---|---|---|
| `feat/` | новая возможность | `feat/auth-jwt` |
| `fix/` | исправление ошибки | `fix/wip-limit-off-by-one` |
| `test/` | только тесты | `test/tasks-api` |
| `docs/` | документация | `docs/api-description` |
| `chore/` | служебные работы | `chore/project-structure` |

## Соглашение о сообщениях коммитов

Формат: `<тип>: <что сделано>`

```
feat: add user authorization stub
fix: correct task position after move
test: add wip limit checks
docs: describe api endpoints
```
