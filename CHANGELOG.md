## [Не выпущено]

### Планируется

- комментарии к задачам;
- история перемещений карточек (журнал действий);
- обновление доски в реальном времени через WebSocket;
- экспорт доски в CSV.

## [0.1.0] - 2026-11-05

Первый выпуск: минимально жизнеспособная версия модуля управления задачами.

### Добавлено

- регистрация и вход по JWT, роли тимлида и разработчика;
- хранение паролей в виде хеша bcrypt;
- доска с пятью колонками: бэклог, к выполнению, в работе, на проверке, готово;
- перетаскивание карточек мышью между колонками с сохранением порядка;
- ограничение на количество задач в колонке «В работе» (не более трёх);
- атрибуты задачи: приоритет, оценка в часах, исполнитель, ветка Git;
- разграничение прав: создание досок и удаление задач доступны только тимлиду,
  разработчик работает со своими задачами;
- фильтр «только мои задачи»;
- автоматическая документация API (Swagger) по адресу `/docs`;
- 30 автотестов серверной части и 7 тестов интерфейса, покрытие кода 97 %;
- конвейер CI: проверка стиля, форматирования, тесты и сборка;
- проверки перед коммитом (pre-commit) и единый стиль кода.

### Исправлено

- вход был невозможен из-за домена `.local` в демонстрационных учётных записях:
  проверка почты отклоняла зарезервированные домены;
- проверка пароля завершалась ошибкой из-за несовместимости passlib с bcrypt 4.x:
  выполнен переход на прямой вызов bcrypt.

### Известные ограничения

- доска одна на команду, выбор между несколькими досками не реализован;
- обновления не приходят автоматически: чтобы увидеть действия напарника,
  нужно обновить страницу;
- журнал перемещений задач не ведётся;
- приложение рассчитано на локальный запуск, публичное развёртывание не настроено;
- база данных SQLite: для нескольких одновременных команд потребуется MySQL
  или PostgreSQL (переход описан в `docs/setup.md`).
